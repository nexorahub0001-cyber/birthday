A LITTLE JOURNEY OF US — Quick Start
=====================================

1. ADD YOUR PHOTOS
   Put 4 photos inside the "images" folder, named exactly:
     photo1.jpg
     photo2.jpg
     photo3.jpg
     photo4.jpg
   (If a photo is missing, that card just shows a placeholder icon — nothing breaks.)

2. ADD A SONG (optional)
   Put an mp3 file inside the "music" folder, named exactly:
     birthday-song.mp3
   There's a small speaker button (top-right of the site) to turn music on/off.

3. OPEN IT
   Double-click index.html to preview it in your browser.

4. EDIT THE WORDS
   Open index.html in VS Code. Search for these sections to personalize:
     - "flirty" answers   (search: flirtyLines / lines array in the script)
     - quiz questions      (search: quizData)
     - choose-one game     (search: choosePairs)
     - the final letter    (search: screen-final, near the bottom of the HTML)

5. PUBLISH IT FREE (so she can open it from her phone)
   - Create a GitHub account (if you don't have one) and a new repository.
   - Upload this whole "birthday-love" folder to that repository.
   - Go to Settings → Pages → set "Deploy from branch" → main → root → Save.
   - GitHub gives you a link like https://yourname.github.io/birthday-love/
     Send that link to her. 💌

That's it — everything else (design, animations, games, the final message)
is already built and working inside index.html.
